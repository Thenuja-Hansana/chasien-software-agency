
A modern, cinematic **digital agency landing page** built with **HTML, Tailwind CSS, GSAP, and Lenis**.  
Designed to showcase premium branding, smooth motion, and immersive interactions.

This project focuses on **visual storytelling**, **micro-interactions**, and **high-performance UI animations** inspired by top-tier agency websites.

---

## ✨ Features

- ⚡ Cinematic hero animations powered by GSAP
- 🧲 Magnetic hover interactions
- 🖱️ Custom cursor & ambient lighting effects
- 🌊 Smooth scrolling using Lenis
- 🔁 Infinite marquee & testimonial slider
- 📱 Fully responsive (mobile → desktop)
- 🎨 Custom Tailwind theme configuration
- 🧠 Performance-oriented UI animations

---

## 🛠 Tech Stack

- **HTML5**
- **Tailwind CSS** (CDN + custom config)
- **JavaScript (Vanilla)**
- **GSAP & ScrollTrigger**
- **Lenis Smooth Scroll**
- **Google Fonts – Space Grotesk**
